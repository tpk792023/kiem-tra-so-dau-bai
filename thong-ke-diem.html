Thống kê kết quả môn học

Thống kê điểm theo lớp, môn, giáo viên từ sổ điểm vnEdu (mức theo Thông tư 22: Tốt ≥ 8,0; Khá 6,5–7,9; Đạt 5,0–6,4; Chưa đạt < 5,0). Chỉ đọc, không sửa điểm. ← Kiểm tra sổ đầu bài · Xếp hạng cuối kì · Kiểm tra ký số

1Lấy điểm từ vnEdu

Trên vnEdu bấm nút dấu trang 📒 Lấy sổ đầu bài → phần Kết quả môn học & file mẫu nhập điểm → chọn học kỳ, khối, phạm vi (Các môn tôi dạy hoặc Tất cả môn) → Thống kê kết quả. Trang này tự mở và nhận điểm. Nếu đã bấm “Chép để dán” thì bấm
File mẫu nhập điểm: ở cùng phần đó bấm Tải file mẫu nhập điểm → nhận 1 file nén, mỗi lớp–môn 1 file Excel đúng mẫu sổ điểm của vnEdu (có sẵn danh sách học sinh). Điền điểm vào file, rồi trên vnEdu mở Sổ điểm – nhận xét → chọn lớp, môn → Nhập từ Excel chọn file đó → kiểm tra các ô tô màu → bấm Lưu. (Phần mềm không tự ghi điểm lên vnEdu để tránh ghi nhầm.)
